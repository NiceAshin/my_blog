# AshinBlog

一个基于 VuePress 的技术博客，记录 PHP、Java、Go 与云原生方向的实践。

## 本地运行

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器预览
npm run build      # 构建静态站点到 .vuepress/dist
```
